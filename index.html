How it works. The page runs the exported ONNX model with ONNX Runtime Web and reads out the 512 feature maps from the last residual block together with the class scores. For a network that ends in global average pooling and a linear layer, the Grad-CAM weight for feature map k is the classifier weight wck divided by the number of positions, so the map is computed directly from the feature maps and the classifier weights, no backward pass needed. The result matches hook-based Grad-CAM on the last block; the model here is INT8-quantized, which shifts heatmap values by about 0.03 on average.
